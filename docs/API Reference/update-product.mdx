# Update Product

Updates an existing product. Give the product's ID in the URL and send the new details as JSON in the request body.

| Method | Endpoint | Purpose |
|---|---|---|
| <Method type="PUT" /> | `/api/products/{id}` | Update an existing product |

:::tip[Try it live]

Test this endpoint in [Swagger UI](https://vikram-swaggerui.onrender.com): open `PUT /api/products/{id}`, select **Try it out**, enter an `id` and a request body, and select **Execute**.

:::

:::note[Demo server]

The live server is a demo that anyone can use, so its data may change or reset at any time.

:::

## Path Parameter

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | integer | Yes | Unique ID of the product to update |

## Request Body

Send every field. The values you send replace the product's current details.

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | Yes | Product name |
| `category` | string | Yes | Category, for example `electronics` |
| `price` | number | Yes | Price. It cannot be negative |
| `stock` | integer | Yes | Units in stock. It cannot be negative |
| `status` | string | Yes | `in_stock`, `out_of_stock`, or `discontinued` |

## Example Request

<Tabs>
<TabItem value="curl" label="curl" default>

```bash
curl -X PUT https://vikram-swaggerui.onrender.com/api/products/1 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Bluetooth Speaker Pro",
    "category": "electronics",
    "price": 59.99,
    "stock": 15,
    "status": "in_stock"
  }'
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const response = await fetch("https://vikram-swaggerui.onrender.com/api/products/1", {
  method: "PUT",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    name: "Bluetooth Speaker Pro",
    category: "electronics",
    price: 59.99,
    stock: 15,
    status: "in_stock",
  }),
});
```

</TabItem>
</Tabs>

## Responses

| Code | Meaning |
|---|---|
| `200` | The product was updated |
| `400` | The input is invalid, for example a missing field, a negative price or stock, or an unsupported status |
| `404` | No product exists with that ID |

<Tabs>
<TabItem value="400" label="400 Invalid input" default>

```json
{

    "message": "Price must be a positive number."
  }
}
```
