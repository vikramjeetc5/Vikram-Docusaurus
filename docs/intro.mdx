# E-Commerce Product Catalog API

Welcome to the **E-Commerce Product Catalog API** documentation.

The E-Commerce Product Catalog API is a RESTful API designed to manage products in an e-commerce catalog. It provides endpoints for creating, retrieving, updating, and deleting products.

The API also supports filtering, sorting, and pagination to make it easier to retrieve and manage product data.

## API Overview

The API provides the following operations:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/products` | Retrieve all products |
| `GET` | `/api/products/:id` | Retrieve a product by ID |
| `POST` | `/api/products` | Create a new product |
| `PUT` | `/api/products/:id` | Update an existing product |
| `DELETE` | `/api/products/:id` | Delete a product |

## Core Features

### Product Management

The API provides complete CRUD operations for products:

- **Create** new products using `POST`
- **Read** products using `GET`
- **Update** products using `PUT`
- **Delete** products using `DELETE`

### Filtering

Products can be filtered using query parameters.

For example:

GET /api/products?category=electronics


Products can also be filtered by inventory status:

GET /api/products?status=in_stock


Supported status values include:

instock outof_stock discontinued


### Sorting

The API supports sorting products using the `sort` query parameter.

Sort by price in ascending order:

GET /api/products?sort=price


Sort by price in descending order:

GET /api/products?sort=-price


Products can also be sorted alphabetically by name:

GET /api/products?sort=name


### Pagination

Product results are paginated to keep response sizes manageable.

The default page size is **10 products per response**.

You can specify a page and limit:

GET /api/products?page=1&limit=5


This requests the first page with a maximum of five products.

## Example Request

Multiple query parameters can be combined in a single request.

GET /api/products?category=electronics&status=in_stock&sort=-price&page=1&limit=5


This request:

1. Filters products by the `electronics` category.
2. Returns only products that are `in_stock`.
3. Sorts products by price in descending order.
4. Requests the first page.
5. Limits the response to five products.

## Interactive API Documentation

The API includes **Swagger UI**, which provides an interactive interface for exploring and testing the available endpoints.

With Swagger UI, you can:

- View all available endpoints
- Inspect request parameters
- View request and response schemas
- Test API requests directly from the browser
- Experiment with filtering, sorting, and pagination
- Test `GET`, `POST`, `PUT`, and `DELETE` operations
