# E-Commerce Product Catalog API

Welcome to the documentation for the E-Commerce Product Catalog API, a REST API for managing the products in an online store's catalog. Use it to create, read, update, and delete products, and to filter, sort, and page through the results.

:::tip[Try it live]

Explore and test every endpoint in [Swagger UI](https://vikram-swaggerui.onrender.com), straight from your browser. The first request after a quiet period may take up to a minute to respond.

:::

## Endpoints

| Method | Endpoint | Description |
|---|---|---|
| <Method type="GET" /> | `/api/products` | Retrieve all products |
| <Method type="GET" /> | `/api/products/{id}` | Retrieve a product by ID |
| <Method type="POST" /> | `/api/products` | Create a new product |
| <Method type="PUT" /> | `/api/products/{id}` | Update an existing product |
| <Method type="DELETE" /> | `/api/products/{id}` | Delete a product |

## What You Can Do With Query Parameters

| Feature | What it does | Example |
|---|---|---|
| Filter by category | Case-insensitive match on the category | `?category=electronics` |
| Filter by status | `in_stock`, `out_of_stock`, or `discontinued` | `?status=in_stock` |
| Sort | `price` (low to high), `-price` (high to low), or `name` | `?sort=-price` |
| Paginate | 10 products per page by default | `?page=1&limit=5` |

You can combine them in one request:

```http
GET /api/products?category=electronics&status=in_stock&sort=-price&page=1&limit=5
```

This returns the first page of up to five electronics products that are in stock, with the most expensive first.

## Quick Start

1. Follow the **Installation** guide to run the API locally.
2. Open **Swagger UI** to explore the endpoints.
3. Try `GET /api/products`, then experiment with filters and sorting.
